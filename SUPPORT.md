# Support

## Where to get help

| What you need | Where to go |
| --- | --- |
| A bug in any thyn-ai product — Algenta, Codna, Telys, Sqai, the accounts portal, or the docs | [Open a bug report](https://github.com/thyn-ai/feedback/issues/new?template=bug_report.yml) here — pick the product in the dropdown and include the version, platform, and a minimal reproduction. From a terminal, `codna report "title" --product <name>` files the same report. |
| A feature or capability request | [Open a feature request](https://github.com/thyn-ai/feedback/issues/new?template=feature_request.yml) here — describe the use case, not just the API or CLI shape you would guess at |
| A usage question with a concrete answer | [Ask a question](https://github.com/thyn-ai/feedback/issues/new?template=question.yml) here, or [Discussions → Q&A](https://github.com/thyn-ai/feedback/discussions/categories/q-a) |
| Ideas, open-ended discussion, show-and-tell | [GitHub Discussions](https://github.com/thyn-ai/feedback/discussions) |
| Real-time chat with the community | [Discord](https://discord.gg/w8NDsph9an) |
| Documentation | [docs.algenta.ai](https://docs.algenta.ai) |
| A change to the code of an open-source product | That product's own repository — see [Related repositories](./README.md#related-repositories) in the README |

Before filing an issue, please search existing issues and discussions — your
question may already have an answer. [CONTRIBUTING.md](./CONTRIBUTING.md)
explains what a report needs to contain to be routed and fixed, and what the
triage labels mean once it is filed.

## Security issues

**Never report a security vulnerability in a public issue, discussion, or
pull request.** Follow [SECURITY.md](./SECURITY.md): the open-source
repositories each have their own policy, and for the proprietary products use
this repository's private **Report a vulnerability** tab or email
`security@algenta.ai`.

## Response expectations

Community support is provided on a best-effort basis by maintainers and other
community members. **There is no SLA for community support** — we triage
reports as time permits, prioritizing security reports (which have their own
response commitments in [SECURITY.md](./SECURITY.md)), data-loss bugs, and
regressions in a product's latest release.

Enterprise customers with a commercial agreement should use their contracted
support channel or the [accounts portal](https://accounts.thyn.ai/account),
or contact community@algenta.ai to be routed. Account-specific details are
never appropriate in a public issue.
